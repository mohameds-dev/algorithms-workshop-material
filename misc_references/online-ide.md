# Online IDE, hassle free

No local setup, no installs. Open https://ide.judge0.com/, pick your language, write code, hit
"Run Code," and see the output in the bottom right panel.

**C++:** in the compiler options field, add `-std=c++20`. Everything in this repo is written to
compile under C++20, so use that and your code will behave the same everywhere.

**Python:** pick Python 3.11 or newer from the language dropdown.
